    Automation

    20 years of machining. Now we add automatic part feeding to CNC machines.

    For 20 years we have made machined and sheet metal parts in Incheon, Korea. Now we are adding a drawer-type automatic part feeder for CNC lathes and machining centers: a cobot takes raw parts from the drawers, loads the machine and puts finished parts back, so the machine keeps running without an operator standing next to it.

    Automatic part feeder and CNC cell concept, virtual factory simulation (2 min)

    Drawer-type automatic part feeder

    • Raw parts and finished parts sit in stacked drawers right next to the machine.
    • A cobot loads the chuck and puts each finished part back in the drawer.
    • When a drawer is finished, the next one slides out automatically.
    • Works with CNC lathes and machining centers, and with different robot brands.

    We are a machine shop ourselves, and we plan each cell in a virtual factory with real dimensions before installing.

    Ask about the part feeder

    How it runs in the cell

    01

    Robot loading

    The robot opens the door, loads the chuck and starts the cycle.

    02

    Automatic drawer change

    The finished drawer goes in and the next one slides out, with no operator needed.

    03

    Any robot brand

    The same feeder and process run with FAIRINO, Universal Robots and Doosan Robotics arms.

    04

    Live data at the machine

    Each machine shows its step, output, cycle time and the parts left in the drawers.

    05

    Operator on call

    When a cell alarms, the operator is called, resets it, and the cell restarts.

    06

    Live data in the office

    Output, cycle time, availability and alarms for every cell on one screen.
